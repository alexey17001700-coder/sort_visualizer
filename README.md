# Визуализатор алгоритмов сортировки

Наглядная анимация сортировок на Python + tkinter. Без сторонних библиотек.

## Запуск

```bash
python main.py
```

Нужен только Python 3.8+ (tkinter идёт в комплекте). Никаких `pip install`.

## Алгоритмы

| Алгоритм | Сложность (средняя) |
|---|---|
| Пузырёк (Bubble) | O(n²) |
| Выбор (Selection) | O(n²) |
| Вставки (Insertion) | O(n²) |
| Быстрая (Quick) | O(n log n) |
| Слияние (Merge) | O(n log n) |
| Куча (Heap) | O(n log n) |

## Управление

- **Алгоритм** — выпадающий список
- **Размер массива** — 10…200 элементов
- **Скорость** — от 1 до 100
- **▶ Старт / ⏸ Пауза** — запуск и пауза
- **🔄 Новый массив** — сгенерировать новые числа
- **⏹ Сброс** — вернуть к началу
- **Пробел** — старт/пауза, **R** — новый массив

## Что видно на экране

- высота столбца = значение элемента
- **красные** столбцы — элементы, которые сейчас сравниваются
- **зелёные** — уже отсортированная часть
- снизу — счётчик шагов и время работы

## Скриншот

Запустите `python main.py` — окно тёмное, столбцы цветные (градиент по величине).
